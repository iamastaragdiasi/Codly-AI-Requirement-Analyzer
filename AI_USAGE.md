# AI Usage Disclosure

## Project
AI-Powered Business Requirement & Project Analysis System

## Human project author
Astarag Diasi

## AI-assisted development
AI tools, including ChatGPT, were used to assist with software
development activities such as implementation guidance, code review,
test design, debugging, and technical documentation.

The human project author is responsible for reviewing the resulting
implementation, validating its behaviour, and deciding which changes
are retained.

## Runtime AI behaviour
The current verified workflow uses a deterministic analysis provider.
Its outputs must not be represented as results from a live AI service.

Live AI integration must use only services, environments, and
credentials explicitly approved by Codly India Private Limited.
No personal API keys or unauthorized client data may be used.

## Human oversight
AI-generated or inferred requirements, scope, estimates, and proposal
content require appropriate human review. AI output does not constitute
client confirmation, final pricing, a delivery commitment, or contractual
approval.

## Testing and limitations
Automated tests provide evidence for the behaviours they exercise;
they do not independently establish production readiness or guarantee
that every requirement in the official specification is implemented.
